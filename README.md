# 國小自然五上第二單元《千變萬化的植物》旗艦互動教學系統

> 依據教育部 108 課綱與**翰林版國小自然科學五上第二單元**（課本 p.40～69）深度研發設計。
> 專為教室大電視投影、電子白板觸控互動、學生平板自主探究所打造的純前端免安裝教學平台。

---

## 🌟 系統亮點功能

1. **大電視投影高對比模式（TV Mode）**：
   - 頂部一鍵切換大字級與高對比，後排學生亦清晰可見。
2. **頂部平滑水平滑動頁籤**：
   - 支援滑鼠滾輪水平滑動（Wheel to Horizontal Scroll），解決傳統網頁頁籤文字過長折行重疊問題。
3. **四大高互動純前端 Canvas 動態模擬器**：
   - **模擬器 1：極端環境植物特化微觀探索器**（海茄苳呼吸根/泌鹽腺、玉山杜鵑厚蠟葉抗風耐寒、布袋蓮膨大氣室浮力組織、木麻黃退化齒葉與板根）。
   - **模擬器 2：植物水分運輸與氣孔蒸散實驗室**（紅墨水芹菜吸收動態微粒流、莖部橫切圓斑點與縱切導管線條剖視、保衛細胞膨脹開閉調節水蒸氣蒸散）。
   - **模擬器 3：花朵解剖受精與種子傳播大冒險**（花萼/花瓣/雄蕊/雌蕊逐步解剖、子房變果實與胚珠變種子動畫、風力/彈力/水力/動物四大種子傳播動態模擬）。
   - **模擬器 4：植物特徵二分法檢索樹互動器**（以大萍、布袋蓮、蓮、樟樹、甘藷、腎蕨六大課本植物為核心，互動建構二叉檢索樹）。
4. **課堂隨堂搶答測驗（10 題精華題）**：
   - 即時反饋、Web Audio 音效、全螢幕彩色彩帶碎紙花、即時解析與計分榜。
5. **13 節完整教案進度表與列印學習單**：
   - 涵蓋 13 節課的探究任務與素養評量指標，內建專屬 `@media print` 樣式，點擊即可一鍵列印黑白高對比學習單。

---

## 🚀 啟動方式

- **Windows 電腦**：直接雙擊執行 `點我啟動教學網站.bat` 或以任何瀏覽器（Chrome、Edge、Firefox）開啟 `index.html`。
- **Mac / Linux 電腦**：直接點擊開啟 `index.html`。
- 免安裝 Node.js、Python 或任何後端伺服器，100% 離線可用！
